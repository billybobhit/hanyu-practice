# Hanyu Practice 🀄

AI-powered Chinese language learning app with ranked progression.

## Features
- Conversational AI tutor in Traditional and Simplified Chinese
- Ranked ELO system (Noob → Eternal) with hidden per-language ELO
- Placement assessment for new users
- Grading rubrics scaled to rank level
- Conversation history per account

## Built With
- Next.js 14, TypeScript
- Supabase (auth + database)
- Anthropic Claude API (via OpenRouter)
- Vercel (deployment)
